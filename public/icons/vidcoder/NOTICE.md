VidCoder's product logo and application icon are not used. ReelCraft Studio retains its own branding. Its toolbar is inspired by VidCoder's Windows interface; remaining generic chevrons, search, and brand scissors use the existing Lucide icons.

Typography reference: VidCoder/App.xaml and VidCoder/View/Main.xaml at the same commit use readable Windows control sizes, including 13/14 px settings text and 14 px section headings. This app uses the Windows-installed Segoe UI family with Myanmar Text fallback; no proprietary Windows font files are bundled.
